# Campaign C/D representation source engineering

5 September 2026; TDD v2 §8.4. This is implemented native source, not an executed UE5.7 acceptance result. No editor authoring or cooked campaign assets were changed.

## Actual integration and authority

`ASovEncounterDirector::SetParticipantRepresentation` converts an explicitly opted-in registered participant at a named allowed boundary. Default eligibility is **false**; the default boundary is `Encounter.ControlledBoundary`. Transitions require authority, an active encounter, current-wave ownership, a living idle stationary grounded actor, no overlapping mutation/promotion, no active attack/reservation, and supported state. Ordinary camera-distance LOD never converts a combatant. Existing A/B decision tiers remain owned by `USovEncounterCoordinationComponent`.

The director captures its existing `FSovEncounterNPCRecord` using the same `CaptureNPC`, Narrative actor/component serialization, stable GUID and resource snapshot used for retry. Its additive current-representation record retains supported GAS and visual fields. This is not another save subsystem or checkpoint owner. The original actor and its controller are destroyed after committing the record/entity; no hidden live combat ASC is parked behind a proxy.

The programmatic `USovCampaignMassVisualizationTrait` builds a real Mass crowd visualization template using the existing `UMassPedRepresentationSubsystem` and `UMassNarrativePedRepresentationActorManagement`. Its participant fragment deliberately excludes `FNarrativePedFragment`/`FNarrativePedProperties`. The existing Narrative spawner selects campaign requests first, bypasses GUID/name reuse and spawns the exact plain `ASovCampaignMassProxy` class through normal Mass spawning. It never chooses a random pedestrian NPC definition.

Tier C uses the native Mass route processor with at most 128 finite corridor points and a bounded speed (0–1200 cm/s). Entity transforms explicitly synchronize to the exact receipt-owned proxy because it has no MassAgent/character translator. Tier D freezes route processing while preserving static/skeletal pose. Both proxy tiers have no controller, GAS, damage, perception or combat collision. This initial implementation supplies pose-held battle presentation, not newly authored ambient animation/Niagara/audio or a replacement navigation/lane system.

## State and boundaries

| State | Native transfer contract |
|---|---|
| Identity and mission ownership | Participant name, Narrative actor GUID, director/encounter identity and required-victory ownership remain fixed. Required demoted participants continue to block wave/victory gates; a missing actor is not a confirmed kill. |
| Position and faction | Current Mass transform wins promotion, not original spawn transform. Exact faction membership is restored through Narrative faction authority. |
| Health, shield, poise, GAS attributes | Existing explicit resource currents and all numeric attribute bases are restored after fresh definition initialization. |
| GAS grants and persistent status | Ability class/level/input/dynamic tags/item owner, tag counts, permanent nonperiodic self effect class/level/stacks/set-by-callers/dynamic tags and evaluated modifier magnitudes are captured. Saved component/item effects retain their component/item removal handles after inventory/component restoration; they are not duplicated as NPC-owned effects. Final ownership/magnitudes/status counts must match before release. |
| Equipment and finite ammunition | Existing Narrative inventory/equipment/component records and explicit wield slots are reused. Visible attached static/skeletal equipment is captured as asset-backed parts; no gameplay weapon is spawned on the proxy. Ammo/refill/recharge rules are unchanged. |
| Sever, weak points and injury | Existing sever-region mask and weak-point/consequence snapshot restore through their authoritative components. Other savable component fields retain Narrative serialization. There is no invented general injury system beyond these existing fields/status effects. |
| Pose | Bone names, component/local transforms, hidden bones, mesh/material assets and relative part transforms are retained. Native poseable meshes render the proxy. Animated promotion calls `UNarrativeAnimInstance::BlendFromRepresentationPose`, reusing its existing `SequencerPoseSnapshot`/blend-request path. Mesh identity, bone names/counts and finite pose data must validate. Arbitrary AnimBlueprint graph state/montage playback is not serialized. |

Promotion creates a fresh saved NPC class, installs definition/spawn overrides/GUID before FinishSpawning, registers the exact pending participant, keeps it hidden/protected, and waits for character appearance readiness. It restores the actor/component record, supported GAS state, resources, faction, wield state, sever/weak points and pose. Only then does it replace the world record, bind the existing coordinator, release that actor's own director suspension, enable presentation and relinquish Mass ownership. Timeout or incompatibility changes the encounter to Failed and keeps the checkpoint/current record available for retry; a partial replacement is never announced as playable.

## Lifetime, saving and explicit refusal

Participant fragments and actor receipts identify director, encounter, participant, actor GUID, entity handle, generation and actor-local binding epoch. Deferred enable/disable validates the live entity identity and project owner before callback-emitting changes. Reusing the same actor with another entity or a new receipt on the same entity invalidates old commands. Receipt state is published before callbacks and invalidated before release. Teardown resolves the authoritative Mass actor fragment even if project visual acceptance failed, cancels pending spawning, releases its matching template actor, and destroys the entity through the Mass command buffer.

Only director current-state records are saved. Entity handles, receipts and proxy actors are transient. Before serialization, entity transform and route progress are copied into the record. Load invalidates old entities/receipts and recreates director-owned representations; active-attempt loads remain Failed under the existing retry policy. Retry invalidates C/D before rebuilding entry NPCs. Failed/restoring/succeeded state freezes routes. Pending replacement never bypasses the existing save-boundary rules.

The following are **refused without converting the original actor**, with an error returned by the director: missing explicit opt-in/boundary, nonactive encounter or pending restore/promotion, active/pending-removal abilities, attack reservations, future-wave staging, outgoing attempt actors, command-link dependency, movement/falling/ragdoll, missing/incompatible appearance, non-Narrative animated-mesh blend contract, dynamic material instances without an asset-backed profile, timed/periodic/external-source/inhibited/linked/execution effects, unsaved effect/grant source ownership, malformed/ambiguous attributes, and budget-exceeding promotion. These actors stay A/B. Source does not claim universal conversion or silently drop their state into a pedestrian template.
