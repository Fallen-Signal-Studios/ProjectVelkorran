# Console compatibility source pass

Scope: Xbox Series X, Xbox Series S, PlayStation 5 and PlayStation 5 Pro. TDD authority remains **Sovereign Call: Origins TDD v2.0, 14 August 2026**, especially sections 18.8–18.9 and the platform baseline. The December attachment is superseded. Existing approved gameplay exceptions remain in force.

This pass extends the merged source-engineering closure from PR #29. It fixes source defects and records the work needed to establish actual console support. **It does not establish a working console build.** Narrative's required runtime modules still exclude console targets, ZenDyn is absent, and no UE 5.7 installation, console platform extensions, SDKs, game content or devkits are available here. The descriptor preflight deliberately reports those blockers.

## Existing systems deliberately retained

- Combat, Echo, weapon state, enemy abilities, severing, weak points and encounter ownership use the existing native/GAS/Narrative systems. No alternate console combat implementation or per-platform gameplay balance is introduced.
- Native checkpoint/manual-save banks and their verified commit/recovery format remain the save authority. Console cloud synchronization must come through the licensed platform save backend. The optional generic `IOnlineUserCloud` comparison/upload UI is disabled on console-style platforms; this is not an implementation of Xbox connected storage or PlayStation save synchronization.
- Ordinary audio output, captions, accessibility gains and controller-speaker fallback remain. A request to use controller audio does not prove a device has a speaker. Console narration, adaptive triggers, device-specific audio and platform accessibility integration remain unverified.
- Unreal's normal settings application remains intact. This patch does not invent Series S memory limits, PS5 Pro enhancement modes, frame pacing, dynamic-resolution floors, certification requirements or SDK configuration keys.

## Next vertical slices

1. **Licensed console build and startup.** Reconcile supported Narrative console modules with these source changes; provide ZenDyn and the complete content; build UE 5.7 Development and Shipping Game targets for each platform using the actual installed SDK. Run the native registrations, then cook/stage/sign/deploy a startup-to-Level-1 build. Done means both consoles boot with their real platform services and no unresolved module/content dependency. Windows editor compilation alone does not satisfy this slice.
2. **Account-owned recovery on hardware.** Finish any provider-specific local-profile/storage integration exposed by this pass. Exercise nonprimary users, offline cold start, signout, reassignment, controller disconnect, nested system screens, suspend during load/cinematic/mission travel, low storage and process termination. Done means the same user's latest durable checkpoint is recoverable, other-user data is inaccessible, no pause/save latch survives incorrectly, and explicit resume restores usable input.
3. **Level 1–2 console performance and presentation.** Run complete missions and worst-case combat/streaming/Mass/sever/cinematic captures separately on Series S, Series X, PS5 and PS5 Pro. Author measured performance/quality profiles; verify large text, safe areas, remapped gamepad controls, HDR/SDR, audio and accessibility devices. Done means recorded frame-time/memory/streaming evidence meets the agreed TDD targets and the missions finish through save/retry/travel on each supported tier.
